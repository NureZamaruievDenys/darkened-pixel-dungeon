### Главная идея архитектуры

**Dungeon.java** - это статический синглтон, содержит **ВСЕ** состояние текущей игры:

```java
public static Hero hero;                    // Главный персонаж
public static Level level;                  // Текущий уровень
public static int depth;                    // На каком уровне находимся
public static ArrayList<Integer> generatedLevels;  // Какие уровни готовы
public static int gold;                     // Золото
public static long seed;                    // Сид для генерации
// ... и много других переменных
```

Все системы работают с **Dungeon** как с центральной точкой данных.

---

### Игровой цикл

```
┌──────────────────────────────────────────┐
│ 1. Ввод игрока (клик на клетку)         │
│    └─→ hero.move() / hero.attack()       │
│    └─→ hero.spend(time)                  │
│                                          │
│ 2. Обработка Actor Queue (все действуют)│
│    while (Actor.hasPending()) {          │
│      Actor next = Actor.next()           │
│      ├─→ Hero                            │
│      ├─→ Mob (враги)                     │
│      ├─→ Blob (газы)                     │
│      └─→ Buff (баффы)                    │
│    }                                     │
│                                          │
│ 3. Проверка конца игры                   │
│    ├─→ hero.isDead() → Defeat            │
│    ├─→ hero.hasReachedAmulet() → Victory │
│    └─→ hero.leftLevel() → Next Level     │
│                                          │
│ 4. Отрисовка (render)                    │
│    └─→ GameScene.draw()                  │
└──────────────────────────────────────────┘
```

## 🎯 Главные компоненты

### Actors (Действующие объекты)
- **Hero** - главный персонаж, управляется игроком
- **Mob** - враги, управляются AI
- **Blob** - эффекты поля (газы, огонь, паутина)
- **Buff** - временные эффекты на персонажей

### Items (Предметы)
- **Weapon** - оружие
- **Armor** - броня
- **Artifact** - артефакты
- **Potion** - зелья
- **Scroll** - свитки
- **Ring** - кольца

### Levels (Уровни)
- **SewerLevel** (уровни 1-2) - сточные каналы
- **PrisonLevel** (уровни 3-4) - тюрьма
- **CavesLevel** (уровни 5-6) - пещеры
- **CityLevel** (уровни 7-8) - город
- **HallsLevel** (уровни 9-10) - залы
- **LastLevel** (уровень 20) - финальный босс

### Scenes (UI Экраны)
- **GameScene** - главная игровая сцена
- **TitleScene** - главное меню
- **HeroSelectScene** - выбор класса

## 💾 Система сохранений

Всё состояние игры сохраняется в Bundle:

```java
Dungeon.saveAll() → Bundle (HashMap) → FileUtils → Disk
```

**Что сохраняется:**
- Hero (персонаж + инвентарь)
- Level (карта уровня)
- Dungeon state (depth, gold, energy и т.д.)
- Statistics (статистика игры)
- Settings (настройки пользователя)
- Rankings (таблица лучших)
- Badges (достижения)

## 🔧 Как расширить проект?

### Добавить нового врага
1. Создать класс наследующий `Mob`
2. Реализовать `act()` с AI логикой
3. Добавить в `Generator`

### Добавить новый баф
1. Создать класс наследующий `Buff`
2. Реализовать `act()` с логикой эффекта
3. Вызвать `buff.attachTo(character)`

### Добавить новый предмет
1. Создать класс наследующий `Item`
2. Реализовать `use()` метод
3. Добавить в `Generator`

### Добавить новый уровень
1. Создать класс наследующий `Level`
2. Реализовать `create()` для генерации
3. Добавить в `Dungeon.newLevel()`

## 🎓 Паттерны проектирования

- **Singleton Pattern** - `Dungeon` класс
- **Observer Pattern** - система Buff
- **Factory Pattern** - `Generator` класс
- **Strategy Pattern** - `HeroClass`, `Mob.AIType`
- **Composite Pattern** - иерархия компонентов UI
- **Command Pattern** - `SPDAction` система управления
